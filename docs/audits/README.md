# Independent audits, August 2026

Commissioned by the Board: fifteen stakeholder audits, four thematic
audits, and one closing question.

**These are deliberately not merged.** Each was written from one
person's vantage point and asks only what that person would ask. Where
two of them reach opposite conclusions from the same fact, both
conclusions stand — that disagreement is the finding, and averaging it
away would destroy the only thing a panel of readers gives you.

Every figure in these documents was measured against the repository or
the record on 23 August 2026, and each is stated with its source so it
can be re-measured. Where an auditor's judgement rests on something not
measurable, that is said.

## The closing question

`24-ten-reasons.md` — the ten remaining reasons an exceptionally
intelligent international applicant might still choose not to enrol.

The Board's instruction was that only when ten convincing reasons cannot
be produced should the institution be considered operationally mature.
Ten were produced without difficulty, and the tenth is not a weak one.
