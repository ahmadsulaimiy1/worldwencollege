# AIPC — Level I, Module 2: Everyday Objects & Places

*Part of `docs/curriculum-level-1-foundation.md`'s Level I build-out.
See that document's module map for this module's can-do focus,
target grammar, and target vocabulary in context.*

**Module learning objectives.** By the end of Module 2, the learner
can: name common objects in a classroom and a home; say what there is
and isn't in a place using `there is/there are`; ask and answer
`Is/Are there ___?`; point out and identify objects using `this/that/
these/those`; name at least 8 common places in a town or city.

**Content map (5 learning items):** module overview & key phrases;
Lesson 2.1 ("There Is / There Are — My Classroom and Home"); Lesson
2.2 ("This, That, These, Those — Around the City"); Module 2 Quiz (8
questions); Module 2 Assignment ("Describe Your Room").

## Lesson 2.1 — "There Is / There Are — My Classroom and Home"

**Learning objectives.** By the end of this lesson you can: (1) name
8+ common classroom and home objects; (2) use `there is` with singular
nouns and `there are` with plural nouns correctly; (3) ask `Is there
a...?`/`Are there any...?` and give short answers (`Yes, there is` /
`No, there isn't`); (4) use `a/an` and plural `-s` correctly with
these nouns.

**Prerequisite knowledge.** Module 1 (`to be`, basic question
formation).

**Warm-up (5 min).** Instructor holds up or points to 4-5 real
classroom objects, naming each once ("This is a book"), then elicits
the name from learners pointing again, no target structure yet — pure
vocabulary noticing.

**Presentation (10 min).** Show a simple picture of a classroom.
Model: "There is a board. There is a teacher's desk. There are ten
chairs. There are some books." Highlight on the board: singular noun →
`there is a/an`; plural noun → `there are`; write the short-answer
pattern for questions: "Is there a window? Yes, there is. / Are there
any pens? Yes, there are."

**Guided practice (10 min).** Learners look at the same classroom
picture in pairs and take turns asking "Is there a...?"/"Are there
any...?" about 6 objects on a given list, answering with short forms.

**Independent practice (10 min).** In pairs, learners describe their
actual real classroom aloud without a picture prompt ("There is a...
There are..."), naming at least 6 real objects around them, then
switch and check each other's sentences.

**Speaking activity.** The independent-practice description above,
plus a quick class survey: each learner asks the instructor one real
`Is there.../Are there...?` question about the school building.

**Listening activity (5 min).** Learners listen to a short description
of an unfamiliar room (read aloud twice) and tick which of 8 pictured
objects are mentioned.

**Reading activity (5 min).** Learners read a short 5-sentence
description of a bedroom and draw/label a simple picture matching what
they read — a genuine reading-to-do-something task, not just
comprehension questions.

**Writing task (5 min).** Learners write 3-4 sentences describing
their own bedroom or living room at home using `there is/there are`.

**Pronunciation practice (5 min).** Drill the weak, unstressed
pronunciation of `there` in `there is/there are` (schwa sound) versus
the stressed `there` meaning "in that place" — a genuinely useful A1
minimal-pair-of-meaning distinction, drilled through contrastive
example sentences.

**Vocabulary reinforcement.** Picture-matching game: classroom and
home objects to their English names, in pairs or small groups.

**Formative assessment.** Instructor monitors guided/independent
practice for correct singular/plural agreement with `there is/are` —
the single most common A1 error this lesson targets.

**Homework.** Learners draw a simple floor plan of one room at home
and label 6 objects in English, ready to describe next lesson.

**Revision.** Lesson 2.2 opens by having learners describe their
homework floor-plan drawing aloud as a warm-up recap.

**Extension activity.** Stronger learners write 2 additional sentences
using negative form: "There isn't a.../There aren't any..."
(previewed, not formally taught until needed).

## Lesson 2.2 — "This, That, These, Those — Around the City"

**Learning objectives.** By the end of this lesson you can: (1) use
`this/these` for near objects and `that/those` for far objects
correctly; (2) name at least 8 common places in a town or city; (3)
ask "Where is the...?" and give a simple location answer; (4)
distinguish singular demonstratives (this/that) from plural ones
(these/those).

**Prerequisite knowledge.** Lesson 2.1 (`there is/are`, classroom/home
vocabulary).

**Warm-up (5 min).** Instructor holds an object close ("This is my
pen") and points to something far across the room ("That is the
door"), modelling naturally before formal presentation.

**Presentation (10 min).** Model dialogue with a simple city map
displayed:
> A: What's this?
> B: This is a bank. And what's that, over there?
> A: That's the train station.
Highlight: `this/that` = one thing (near/far); `these/those` = more
than one thing (near/far). Introduce 8 city-place words using the map
(bank, school, hospital, restaurant, supermarket, park, station,
hotel).

**Guided practice (10 min).** Pair work with the same city map:
Learner A points to a near place and asks "What's this?", Learner B
answers; then a far place with "What's that?" — 6 rounds each,
swapping roles.

**Independent practice (10 min).** Learners create their own simple
"my neighbourhood" sketch map with 5 places labelled, then describe it
to a partner using `this is.../these are...` for their own map and
`that is.../those are...` for a place they point to on their partner's
map.

**Speaking activity.** The map-description exchange above.

**Listening activity (5 min).** Learners listen to a short set of
directions naming 4 city places in sequence and number them in the
order mentioned on a simple map worksheet.

**Reading activity (5 min).** Learners read 4 short signs (e.g. "City
Hospital — Open 24 Hours", "Central Park — No Bicycles") and match
each to the correct place-type picture.

**Writing task (5 min).** Learners write 4 sentences naming places in
their real town/city using `this is/these are` for nearby familiar
places.

**Pronunciation practice (5 min).** Drill the `/ð/` sound in
this/that/these/those (linking to Module 1's `/θ/`/`/ð/` introduction)
and the vowel-length contrast between `this` (short /ɪ/) and `these`
(long /iː/), a common A1 confusion pair.

**Vocabulary reinforcement.** City-places bingo or matching game using
the 8 words introduced.

**Formative assessment.** Exit ticket: learner names one real nearby
object with `this/these` and one real far object with `that/those`.

**Homework.** Learners find (or draw) a picture of one place in their
own town not covered in class and bring the English name next lesson.

**Revision.** This lesson opens with the homework floor-plan recap
from Lesson 2.1 (see above). Module 2's Quiz and Assignment draw on
both lessons.

**Extension activity.** Stronger learners write a short 4-sentence
"tour guide" description of their neighbourhood mixing `there is/are`
(Lesson 2.1) with `this/that/these/those` (this lesson).

## Module 2 Quiz (auto-graded, 8 questions)

*Seeded verbatim into `quiz_questions` — see
`sql/seed-curriculum-level-1.sql`. Answer key marked with ✓.*

1. "___ a book on the table." — (a) There is ✓ (b) There are (c) This
   is (d) These are
2. "___ any chairs in the room?" — (a) Is there (b) Are there ✓ (c) Is
   this (d) Are these
3. Pointing at something in your hand: "___ is my pen." — (a) That
   (b) Those (c) This ✓ (d) These
4. Pointing at something across the room: "___ is the door." — (a)
   This (b) These (c) That ✓ (d) Those
5. "There ___ ten students in my class." — (a) is (b) are ✓ (c) am (d)
   be
6. Which place do you go to buy food? — (a) hospital (b) station (c)
   supermarket ✓ (d) hotel
7. "___ are my books." (pointing at several books near you) — (a)
   This (b) That (c) These ✓ (d) Those
8. "Where ___ the bank?" — (a) is ✓ (b) are (c) am (d) do

## Module 2 Assignment — "Describe Your Room"

**Instructions given to the learner:** Write (or record yourself
speaking) 5-6 sentences describing one room in your home. Use `there
is/there are` for at least 3 objects, and `this is/that is/these are/
those are` for at least 2 objects. Say or write one sentence naming a
place near your home (a shop, park, or similar) using vocabulary from
this module.

**Grading rubric (for the instructor):**
- **Grammatical accuracy** — correct `there is/are` singular/plural
  agreement; correct demonstrative choice (near vs. far, singular vs.
  plural).
- **Vocabulary range** — at least 5 distinct objects/places named
  correctly from this module's target vocabulary.
- **Task completion** — all required sentence types present.
- **Clarity** — the description is understandable as a real room, not
  a disconnected list of nouns.

A grade at or above the platform's pass threshold marks Module 2
completed for the learner.
