The Register

Named institutional roles, not h1–h6. A role says what a line is in a document, so two engineers reach for the same one.

Article — the sub-heading role, set on the display face at optical size 36.

Clause — running prose, capped at a 34em measure at every viewport width, because a line the eye cannot return from is not a line it will read twice.

Cartouche · the inscriptional face, rationed

Marginalia — the marginal track, condensed to wdth 96.

Colophon — the smallest role in the system.
