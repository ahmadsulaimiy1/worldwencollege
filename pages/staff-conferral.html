        What conferring does

        It writes a link in a chain

        Each conferral carries the digest of the one before it, so the register can be shown to be complete and unaltered from its first entry. A row cannot be quietly edited afterwards; it can only be withdrawn or replaced, and both are recorded.

        It is signed, and anybody can check it

        The award is signed with the College’s current key at the moment it is conferred. From then on a stranger with the code can verify it at the verification portal, without an account, for as long as the College exists.

        And the wording is permanent

        The title, the post-nominal, the honour and the citation are stored on the award itself rather than looked up later, so a certificate conferred today still reads as it did on the day whatever the College renames afterwards. That is also why none of them is typed here.
